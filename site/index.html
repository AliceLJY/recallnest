RecallNest 是一层本地优先的共享记忆：Claude Code、Codex、Kimi、Antigravity 读写同一个记忆库。一个窗口里存下的上下文，换个窗口、换台机器也能召回。RecallNest is a local-first memory layer that Claude Code, Codex, Kimi and Antigravity all read and write. Context saved in one window can be recalled in another — even on another machine.

01 · 散落Scattered

每开一个新窗口，它就失忆一次。Every new window forgets everything.

项目配置、调试时拍板的决定、谁是谁——散落在各个客户端各自的会话里，彼此看不见。Project configs, decisions made while debugging, who is who — scattered across each client's own sessions, invisible to one another.

02 · 汇成一份One store

一个记忆库，所有客户端共读共写。One store. Every client reads and writes it.

命令行 agent 和支持 MCP 的桌面 app 走 MCP（stdio）；只会发 HTTP 的脚本走 HTTP API；手机走只读网关。换到另一台机器，把启动命令换成 ssh，就和家里那台共用同一份。CLI agents and MCP-capable desktop apps connect over MCP (stdio); scripts that only speak HTTP use the HTTP API; a phone goes through a read-only gateway. On another machine, swap the launch command for ssh and it shares the same store.

03 · 编进巢里Woven in

不是一堆日志，是分好类的记忆。Not a pile of logs. Memory, sorted.

每条记忆归进 6 类：身份、偏好、实体、事件、案例、模式。每条都存三种粒度——一句话、要点、全文，召回时按相关度和 token 预算挑一层给你。同一个判断被修订时，新版接替旧版，旧版留作历史。Every memory lands in one of six categories — profile, preferences, entities, events, cases, patterns — and is kept at three granularities: one line, key points, full text. Recall picks the layer that fits the relevance and the token budget. When a judgment is revised, the new version supersedes the old one, which stays as history.

04 · 唤回Recall

问一句，相关的自己浮上来。Ask once. What matters rises.

默认走向量检索，需要时再打开 BM25 全文、多粒度向量和知识图谱。每条记忆写入时还能附 2–6 句「以后会怎么问起它」，单独嵌入、只管召回，不当证据。Vector search by default; turn on BM25, multi-granularity vectors and a knowledge graph when you need them. A memory can carry 2–6 "how will I ask about this later" phrasings — embedded separately, used only for recall, never shown as evidence.

05 · 该淡的会淡Fading on purpose

会遗忘，也知道什么不能忘。It forgets — and knows what not to.

记忆沿 Weibull 曲线衰减，重要度调节半衰期。模式类不按时间衰减；钉住的、7 天内用过的、核心且重要度 ≥ 0.95 的也不衰减。从会话记录里抓来的片段只算证据，要升格成你做过的决定，得另过一道要证据的关。Memories decay along a Weibull curve, with importance shaping the half-life. Patterns are exempt from time decay, and so are pinned memories, anything used in the last 7 days, and core memories with importance ≥ 0.95. Fragments pulled from transcripts stay evidence; becoming a decision you actually made is a separate, gated step.

06 · 回到同一个巢Back to one nest

下个窗口打开时，交接已经在等你。The next window opens to a handoff.

退出时 checkpoint_session 记下这一段的决定和待办，新窗口里调一次 resume_context 就接上。召回的状态只当交接参考，不会冒充仓库此刻的样子。On exit, checkpoint_session records the decisions and open loops; in the next window, one resume_context call picks them up. Recalled state is a handoff, never a claim about what the repo looks like right now.
